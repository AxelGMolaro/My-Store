## 📦 Project Overview

This project is a **mini e-commerce application** that includes:

-   A navigation menu\
-   A product listing\
-   Shopping cart logic

------------------------------------------------------------------------

## 🚀 Getting Started

To run this project locally:

``` bash
npm install
npm run start
```

Then open your browser at:

http://localhost:4200
